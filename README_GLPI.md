> Complemento ao README principal com detalhes técnicos da versão em plugin GLPI.

Consulte o [README.md](README.md) para visão geral do projeto — o que é, para que serve e destaques.

## Sobre este documento

Este plugin estende o sistema de Protocolo de Pastas para funcionar nativamente dentro do GLPI 11, utilizando usuários, perfis e entidades da plataforma. Reaproveita toda a lógica de protocolo, geração de termos e arquivamento, agora integrada ao ecossistema GLPI.

## Compatibilidade

- GLPI 11.0 → 12.0
- PHP 8.1+
- MariaDB / MySQL
