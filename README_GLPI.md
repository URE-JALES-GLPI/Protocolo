# Protocolo de Pastas — Plugin GLPI

> Complemento ao README principal com detalhes técnicos da versão em plugin GLPI.

Consulte o [README.md](README.md) para visão geral do projeto — o que é, para que serve e destaques.

## Sobre este documento

Este plugin estende o sistema de Protocolo de Pastas para funcionar nativamente dentro do GLPI 12, utilizando usuários, perfis e entidades da plataforma. Reaproveita toda a lógica de protocolo, geração de termos e arquivamento, agora integrada ao ecossistema GLPI.

## Compatibilidade

- GLPI 12.0.0 → 12.0.99
- PHP 8.2+
- MariaDB / MySQL
